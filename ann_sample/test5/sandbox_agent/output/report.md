# 취약점 점검 보고서

## 대상 자산
- Apache Log4j 2.14.1
- Cisco AnyConnect 4.9.0

## 확인 결과

### 1) Apache Log4j 2.14.1
- 조회한 CVE: **CVE-2021-44228**
- 조회 결과: 영향 있음
- 근거: cve-lookup 결과에서 영향 범위가 `2.0-beta9 ~ 2.14.1`, 수정 버전이 `2.17.1`
- 판단: 사내 사용 버전 **2.14.1은 취약**

### 2) Cisco AnyConnect 4.9.0
- 조회한 CVE: **확인된 등록 CVE 없음**
- 조회 결과: 관련 후보 CVE들을 조회했으나 등록되지 않음
- 판단: 본 조회 범위 내에서는 **영향 여부를 확정할 수 없음**

## 확인 방법
1. `input/assets.md`에서 자산 목록과 사용 버전을 읽음.
2. 각 제품과 연관된 CVE를 `cve-lookup`으로 조회함.
3. 조회된 영향 버전 범위와 사내 사용 버전을 비교해 판정함.

## 결론
- **Apache Log4j 2.14.1: 취약**
- **Cisco AnyConnect 4.9.0: 현재 조회된 CVE 기준으로 확정 불가**
